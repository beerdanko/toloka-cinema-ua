# Toloka Series UA

Окремий каталог серіалів, що з'явилися з українським аудіо на Toloka.

Працює паралельно з уже налаштованими **фільмами** — `build_catalog.py` і `data/catalog.json` не змінюються.

## Що отримуємо
- До 60 серіалів за появою нових релізів у джерелі, не за сідами чи датою першої прем'єри.
- IMDb >=7.5 і >=20 000 голосів, без аніме, мультфільмів, документалок, реаліті, новин; супергероїку відсікаємо за ключовими словами TMDb, коли вони наявні.
- Розділення серіалів / сезонів / серій; 1080p/4K із ознакою українського аудіо.
- Два релізи одного сезону з різною якістю не створюють дубль серіалу.
- Кількість серій розпізнається з назв роздачі. Якщо назва не вказує, які серії всередині, Kodi показує список серій із TMDb як **непідтверджений**: їх наявність перевіряє Elementum. Майбутні серії, на які є дата прем’єри, не показуються.
- Публікує `data/shows.json`, каталог у Kodi оновлюється при повторному відкритті.

## Запуск

1. Додайте у наявний репозиторій `beerdanko/toloka-cinema-ua` вміст цього ZIP, зберігаючи структуру папок, включно з прихованою `.github/workflows/update-shows.yml`.
2. Збережений `TMDB_READ_TOKEN` використовується автоматично; новий ключ не потрібен.
3. GitHub → Actions → `Update Toloka Series UA` → Run workflow (main).
4. Відкрийте `data/shows_report.json` для кількості знайдених серіалів та `data/shows.json` для перевірки каталогу.
5. Встановіть `plugin.video.tolokaseriesua-0.1.0.zip` у Kodi через пункт «Встановити з ZIP».

Живий запуск на Toloka і Xiaomi **ще не проводився**; локальні тести лише перевіряють алгоритм.

Прототип не гарантує, що всі серії мають активних сідів. Якщо потрібні лише перевірені серії, із назв роздач обираються лише явно вказані номери; за відсутності номерів у метаданих відображаються потенційні серії TMDb із попередженням.

Для перевірки без ключа: `python build_shows.py --demo --catalog /tmp/shows.json --state /tmp/shows_state.json --report /tmp/shows_report.json`. Демонстраційні дані не використовуйте в реальному каталозі!
