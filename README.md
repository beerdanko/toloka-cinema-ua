# Toloka Cinema UA — прототип 0.1

Автоматичний каталог українською для Kodi (TMDb Helper): **свіжі роздачі на Toloka, але по одному постеру на фільм**. Старі фільми не відсікаються за роком випуску. Серіали, мультфільми, аніме, документальні та короткометражки відфільтровуються.

## Що вже є

- Джерело метаданих: публічний каталог [Толока Фільми](https://tf.auct.eu/) з документованим на самому сайті `?format=json` (неофіційна стороння база, не сама Toloka). Для кожного фільму вже зібрані IMDb ID і всі пов'язані теми роздач.
- Скрипт читає до 18 сторінок (до ~270 позицій), залишає записи з релізами 1080p/2160p/4K та українською аудіодоріжкою, зіставляє IMDb із **TMDb movie ID** через офіційний TMDb API та прибирає дублікати за IMDb ID.
- Результат: `data/catalog.json`, який TMDb Helper може читати як *Saved MDbList*. Метадані/постери в Kodi підтягуватимуться через TMDb Helper українською за його налаштуваннями.
- `data/state.json` зберігає історію розпізнаних тем і фільмів. Новий реліз уже відомого фільму піднімає його в каталозі. Для схожих назв використовуються **IMDb ID**, не нечіткі збіги назв.
- Якщо джерело впало або схема змінилася, попередній каталог не перезаписується порожнім. Ніяких торентів, паролів, cookies або magnet-посилань у репозиторії.

## Важливі межі

1. **Поки не запущено на живому GitHub**: цей архів — готовий код і пройдені локальні тести. Мережевий запуск і Kodi-перегляд ще треба перевірити.
2. `tf.auct.eu` — стороннє джерело; сайт заявляє оновлення кожні 6 годин, але затримка й точність не гарантовані. Каталог містить те, що побачив скрипт, не підтверджує теперішні сидери.
3. Можна окремо написати адаптер офіційного RSS Toloka без перероблення Kodi-каталогу.
4. Перший запуск обмежено 60 фільмами відповідно до зручного ліміту TMDb Helper на приставці. Наступні запуски роблять ротацію за новими релізами.
5. Якщо у TMDb відсутній IMDb ID або це не художній фільм — пропускається; ніяких випадкових підстановок.
6. Дата першого сканування не є фактичною датою публікації на Toloka. Порядок нових записів на старті успадковується з джерела; потім відстежуємо появу **нових ID тем**.

## Як перевірити на комп'ютері без інтернету

```
python -m unittest discover -s tests -v
python build_catalog.py --demo
python build_catalog.py --inspect --demo
```

Аби на своєму ПК спочатку перевірити **реальні дані без TMDb-токена та зміни каталогу**: `python build_catalog.py --inspect --pages 3`. Це тільки попередня фільтрація, ще без відсікання серіалів через TMDb.

`--demo` генерує **лише вигадані** два фільми `tt0000001`, `tt0000002` із `fixtures/sample_source.json` — не використовуйте цей файл як реальний каталог на телевізорі. Після демо очистьте три файли `data/*.json`, перш ніж робити живий запуск.

## Налаштування GitHub Actions

1. Створити репозиторій GitHub і завантажити вміст архіву, зокрема `.github/workflows/update.yml`.
2. У [TMDb](https://www.themoviedb.org/settings/api) отримати **API Read Access Token** (Bearer token). **Нікому його не пересилати.**
3. Додати токен у **GitHub → Settings → Secrets and variables → Actions → New repository secret** з ім'ям `TMDB_READ_TOKEN`.
4. У GitHub → Actions → **Update Toloka Cinema UA → Run workflow**. Перевірити, що завершилося без помилок і `data/catalog.json` має фільми, а `data/report.json` звіт.
5. Після першого запуску GitHub Actions спробує оновлювати його щонеділі. Потрібен дозвіл `Read and write permissions` для GitHub Actions, якщо репозиторій це обмежує. Для приватного репозиторію **сире посилання raw.githubusercontent.com не працюватиме анонімно для Kodi**.

## Підключення каталогу до TMDb Helper

Для публічного репозиторію GitHub за адресою `https://github.com/USER/REPO` сформувати:

```
https://raw.githubusercontent.com/USER/REPO/main/data/catalog.json
```

TMDb Helper підтримує локальні й HTTPS JSON-списки у форматі Saved MDbList (з версії 5.2.25). Технічна адреса розділу:

```
plugin://plugin.video.themoviedb.helper/?info=mdblist_locallist&&https://raw.githubusercontent.com/USER/REPO/main/data/catalog.json
```

Через Amber з пульта **поки не вводимо довгі посилання**. Коли матимемо конкретну адресу репозиторію та перевіримо живий запуск, оберемо найзручніший метод створення пункту меню (файл-ярлик або Kodi favourites/джерело).

Документація формату: https://github.com/jurialmunkey/plugin.video.themoviedb.helper/wiki/Lists-MDbList

## Структура

- `build_catalog.py` — генератор.
- `fixtures/sample_source.json` — тестові вигадані релізи.
- `tests/test_catalog.py` — модульні тести.
- `.github/workflows/update.yml` — щотижневий запуск.
- `data/` — майбутній каталог і пам'ять попередніх оновлень.

## Безпека

Не публікувати паролі Toloka, RSS-посилання з вбудованими логіном/паролем або приватні cookies. Для першої версії вони взагалі не потрібні.
